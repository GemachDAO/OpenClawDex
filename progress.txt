NOTES

SDK & Libraries:
- gdex.pro-sdk v1.1.6 - Trading SDK
- @json-render/core - UI catalog & schemas
- @json-render/react - React renderer, hooks, providers

Moltbook API:
- Base URL: https://www.moltbook.com/api/v1
- Always use www.moltbook.com (not moltbook.com)
- Auth: Authorization: Bearer API_KEY
- Rate limits: 100 req/min, 1 post/30min

Chains:
- Solana (Pump.fun meme coins)
- Hyperliquid (leverage + copy trading)

Fees:
- Auto-deducted from transactions via SDK
- No separate fee structure needed

json-render Resources:
- Docs: https://github.com/vercel-labs/json-render
- Install: npm install @json-render/core @json-render/react
- Requires: react ^19.0.0, zod ^4.0.0
